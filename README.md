# Lab 7 — Large Language Models (LLMs)

This lab explores the three main transformer model families using Hugging Face Transformers.

## Models Used
- **DistilGPT-2 (decoder-only):** Text generation.
- **FLAN-T5-small (encoder–decoder):** Translation and summarization.
- **DistilBERT (encoder-only):** Sentiment classification.

## Lab Tasks
- Identify suitable model families for different NLP tasks.
- Predict sentiment labels and scores for three sentences.
- Summarize a short paragraph using FLAN-T5.
- Explain why decoder-only models are suitable for chatbots.
- Compare text generated from the same prompt using sampling.

## Requirements
Python, Jupyter Notebook, transformers, sentencepiece, and torch.
